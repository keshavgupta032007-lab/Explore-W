# Explore-W - travel website (HTML / CSS / JavaScript + selected React components)

The site is still a normal **multipage HTML website**. React now renders the main content of these pages:

| Page | Mount point (`id`) | React component | What it does |
|---|---|---|---|
| `html/index.html` | `#react-featured` | `FeaturedDestinations` | Popular destination cards with favorites; "Explore" opens Packages with that destination searched |
| `html/packages.html` | `#react-packages` | `PackageExplorer` | Search, region / style / price filters, sorting, favorites panel, "Book now" |
| `html/booking.html` | `#react-booking` | `BookingPage` | Controlled booking form with validation + live price summary |
| `html/flights.html`, `hotels.html`, `trains.html`, `buses.html`, `cabs.html` | `#react-results` (`data-service`) | `ResultsPage` | One component for all five: search bar, price / rating filters, sorting, result cards, "Book Now" |
| `html/my-trips.html` | `#react-trips` | `MyTripsPage` | Saved bookings with cancel |
| `html/contact.html` | `#react-contact` | `ContactForm` | Controlled form with validation and a confirmation toast |

Login, signup, profile and about remain plain HTML/CSS/JS.

## Run it (VS Code terminal)

```bash
npm install        # once
npm run dev        # same as: npm start
```

`npm run dev` builds the React code, starts a local server, opens `http://localhost:5173/html/index.html`
in your browser, and rebuilds + reloads automatically every time you save a file in `react/`, `html/`, `css/` or `javascript/`.
Stop it with Ctrl+C. Requires Node 18+.

Other commands:

```bash
npm run build      # one-off build: react/ -> react-dist/explore-react.js + explore-react.css
npm run watch      # rebuild on save, without the server
npm run format     # format all code in react/ with Prettier
```

You can also open `html/index.html` directly (or use VS Code "Live Server") as long as `react-dist/` has been built.

## How React is mounted

```
HTML page  --loads-->  react-dist/explore-react.css  and  react-dist/explore-react.js
                         (built from react/main.jsx by Vite)
```

1. A page contains an empty container, e.g. `<div id="react-packages"></div>`.
2. `react/main.jsx` looks for the known container ids and calls `createRoot(container).render(<Component />)` for each one it finds. Pages without a container are untouched.
3. Everything inside a container belongs to React. The old JavaScript never touches those elements (`results.js` and `booking.js` were removed from the pages whose content React now renders; `javascript/nav.js` keeps the mobile menu working).
4. The bundle is built as a classic script (IIFE) so pages still work when opened with `file://`.
5. The static HTML left inside `#react-featured` is a fallback that is replaced when React starts.

## Changes to existing files

- `html/index.html`, `html/packages.html`, `html/booking.html`: mount points, React css/js links; packages page no longer has the old (non-working) checkbox filters; booking page wording changed from "Secure checkout / Booking confirmed" to "Demo checkout / Booking saved".
- `javascript/booking.js`: removed (replaced by `BookingPage.jsx`).
- `javascript/data.js`: the `packages` list moved to `react/data/packages.js` so there is one source of truth.
- `javascript/my-trips.js`: booking details are now HTML-escaped before display; shows travel date and traveller count.
- `javascript/results.js`: fixed the price slider (step/min were set after the value, so the most expensive flight was hidden by default).

## Limitations / needs a backend

- No real payment, availability or confirmation: bookings are only saved in the browser's `localStorage`.
- Login/signup also use `localStorage` (passwords stored in plain text) - fine for a demo, **not** for production. A real site needs a server and hashed passwords.
- Prices, ratings and the travel-insurance add-on are sample data.
- Favorites and bookings are per-browser; they do not follow the user to another device.
- Package photos load from Unsplash (internet needed). Swiss Alps and New York have no photo yet and show a placeholder: set `image` in `react/data/packages.js`.
- The filter checkboxes on flights/hotels/trains/buses/cabs pages ("Free cancellation", ...) were already non-functional and were left as they were.
